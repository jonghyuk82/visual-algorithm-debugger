# Visual Algorithm Debugger

A web-based visual debugger for exploring C# algorithms step by step.

## Overview

Visual Algorithm Debugger helps developers understand how C# algorithms execute by visualizing execution state step by step.

The application will provide visibility into:

- Executed source lines
- Variable values
- Call stacks
- Arrays and collections
- Linked lists
- Binary trees
